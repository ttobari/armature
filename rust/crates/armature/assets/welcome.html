Welcome

A plain desk for running Claude Code from your tasks.
It is meant to be a starting point: you add the tools you want.

1The window

LeftBrowser tabs
Running sessions
CenterClaude Code in a terminal. Open as many tabs as you like; conversations keep running when you close the window.
RightClock
Tasks

The side panels can be shown, removed and rearranged: ask Claude to “move the clock to the left column”.

2The first time only

Claude Code in the center asks whether you trust the folder. Choose Yes, I trust this folder. The folder is the app's own (~/Armature), and it won't ask again.

Claude Code needs a Claude plan such as Pro or Max. The first time, a sign-in page opens in your browser.

3Working from tasks

  1. Ask Claude in the center: “Add a task to …”. It shows up in the list.
  2. Select it and press ⌃L. A Claude session for that task opens in the center.
  3. Claude reads the task file to start, and at natural break points writes “Where it stands” and “Next steps” back into it. Say “save” and it writes them right away.
  4. The next time you start that task, it picks up from there.
  5. When it's finished, press d twice in the list to mark it done.

Tasks are plain Markdown files, one per task, in ~/Armature/tasks/. Edit them in any editor you like.

4Keys you'll use

⌘TNew Claude tab
⌘JNew shell
⌘WClose the current tab
⌃TabNext tab
⌘BSwitch between the browser and the terminal (T translates a foreign page into English)
⌘RGo to the task list (while a page is showing, ⌘R reloads it: press ⌘B first)
⌘,Settings (language, color theme)
⌘/Every key (there are more)

5Make it your own desk

Panels can be replaced, removed, or built for you by Claude. The panel layout is one file, ~/Armature/panels.conf: edit it by hand, or just ask Claude to “move the clock to the left column”.

Weather, notes, feeds, a Git diff — the source is written so that you can ask Claude Code to “add a panel” and get the one you want.

Close this page with ⌘W. ⌘B takes you back to the terminal.
