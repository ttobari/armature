ようこそ

Claude Code をタスクから起こして回すための、まっさらな机です。
ここから自分の道具を足していく前提で作ってあります。

動いているセッション
中央Claude Code の端末。タブで何本でも並べられて、窓を閉じても会話は生きています。
右時計
タスク

左右のパネルは、出す・外す・入れ替えが自由です。Claude に「時計を左の列へ」と頼めば並べ替わります。

2最初の一回だけ

中央の Claude Code が「このフォルダを信頼するか」を聞いてきます。Yes, I trust this folder を選んでください。フォルダはこのアプリの置き場(~/Armature)で、次からは聞かれません。

Claude Code を使うには Claude の Pro / Max などの契約が要ります。初めて使うときは、ブラウザでログインの画面が開きます。

3タスクで回す

  1. 中央の Claude に「〇〇をタスクに足して」と頼みます。一覧に 1 件増えます。
  2. 一覧で選んで ⌃L。そのタスク用の Claude が中央に立ち上がります。
  3. Claude はタスクのファイルを読んで始め、区切りのいいところで「現在地」と「次にやること」を書き戻します。「保存」と言えばすぐに書きます。
  4. 次にそのタスクを起こすと、書き戻したところから続きます。
  5. 終わったら一覧で d を2回。完了になります。

タスクは ~/Armature/tasks/ に1件1枚の Markdown で置かれます。ふつうのファイルなので、好きなエディタで直せます。

4よく使うキー

⌘T新しい Claude のタブ
⌘J新しいシェル
⌘Wいまのタブを閉じる
⌃Tab次のタブへ
⌘Bブラウザと端末を切り替える(外国語の頁は T で日本語に)
⌘Rタスクの一覧へ(頁を見ている間は頁の読み直しになるので、先に ⌘B)
⌘,設定(言語・配色)
⌘/キーの一覧(このほかにもあります)

5自分の机にする

パネルは差し替えも取り外しも自由で、Claude に作ってもらうこともできます。パネルの並びは ~/Armature/panels.conf 1枚に書いてあり、手で直しても、Claude に「時計を左の列へ」と頼んでも変えられます。

天気、ノート、フィード、Git の差分——欲しいパネルは、ソースを手元に置いて Claude Code に「パネルを足して」と頼めば作れるように書いてあります。

この頁は ⌘W で閉じられます。⌘B で端末に戻ります。
